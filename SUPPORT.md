# Support

adobe-mcp is maintained by one person. Support is best-effort, with no SLA.

- **Questions and bugs:** open a [GitHub issue](https://github.com/zachshallbetter/adobe-mcp/issues/new/choose). For a bug, include the package and its version, the Adobe application and its version, and the tool and arguments involved.
- **Security reports:** follow [SECURITY.md](SECURITY.md). Do not open a public issue.
- **Versions:** each package is versioned and released on its own by git tag, and published to npm. Only the supported versions listed in [SECURITY.md](SECURITY.md) receive security fixes.
